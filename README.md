HopSession 🍻

A private web app for friends to organize beer-tasting events and split the costs smartly (like Splitwise for beer).
Tech Stack

    Frontend: React + TypeScript (Vite)

    Styling: Tailwind CSS + shadcn/ui

    Backend & DB: Convex

Quick Start

    Install dependencies: npm install

    Start Convex backend: npx convex dev

    Start Vite dev server: npm run dev
